# 🛍️ Retail Sales Analysis – MSIB Project

Proyek ini dibuat dalam program MSIB untuk menganalisis data penjualan video games. Tujuan dari proyek ini adalah menganalisis data ini untuk mengidentifikasi penyebab penurunan penjualan video game secara global dalam tiga tahun terakhir. Kami memilih menganalisis permasalahan ini karena tahun tersebut merupakan puncak penurunan terendah sepanjang sejarah. Kami berharap hasil analisa kami dapat menyelesaikan permasalahan yang terjadi dan memberikan solusi. agar permasalahan penurunan serupa tidak terjadi lagi

## 🔍 Analisis yang Dilakukan

Analisis ini mencakup beberapa langkah, yaitu:
- **Total penjualan per tahun**: Mengetahui tren penjualan selama lima belas tahun terakhir.
- **Penerbit paling laku**: Mencari tahu penerbit yang terjual paling banyak.
- **Kategori genre game dengan penjualan terbesar**: Menilai performa genre game tertentu.
- **Menampilkan game yang memiliki penjualan terbanyak**: Menilai 5 game dengan penjualan terbanyak
- **Visualisasi interaktif**: Menggunakan Looker Studio untuk menampilkan dashboard yang memberikan gambaran secara real-time.

## 📌 Insight Penting
Dari hasil analisis, beberapa insight penting yang ditemukan:
- Selama tiga tahun terakhir, penjualan video game secara global mengalami penurunan.
- Nintendo adalah penerbit paling sukses dalam penjualan video game diikuti oleh Electronic Arts dan Activision.
- Game Wii Sport mendominasi penjualan dengan angka tertinggi.
- Aksi adalah genre terlaris diikuti oleh Olahraga, Penembak, dan Lain-Lain.
- Game Wii Sports memimpin penjualan di Amerika Utara dan Uni Eropa, sementara GTA: San Andreas lebih populer di wilayah lain, dan New Super Mario Bros menjadi pilihan utama di Jepang.

---

## 🧠 Kesimpulan
Penjualan video game secara global mengalami penurunan dalam 3 tahun terakhir, tepatnya setelah rekor penjualan global tertinggi pada tahun 2008 sebesar 688,29 Juta game. Menyikapi penurunan penjualan, memfokuskan pengembangan game pada platform, genre, dan pemasaran yang mendominasi pasar dapat membantu mengatasi penurunan tersebut.
